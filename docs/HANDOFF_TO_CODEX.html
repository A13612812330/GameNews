六、必须遵守的约定（红线）

  • Steam AppID 是 games 唯一主键；steam_snapshots 只追加不覆盖。
  • AI 结论只写 ai_analyses，禁止写回 articles/events/games 原始字段；未配置模型前禁止真实推理与自动发布。
  • 统一规则层唯一入口：清洗/去重/评级必须从 server/rules/index.mjs 导入，禁止各出口自己实现。
  • 迁移只增不删；保留 legacy_id / source_system；不丢弃人工评级与原文链接（articles.detail_url）。
  • 数据等级分离：realtime / history / demo 不得混排；①搜索源是演示数据。
  • 未完成 OPS-01/02/03 前不得暂停旧任务（GameNews 仍在实际发送飞书提醒）。
  • 旧库只读：GameNews/WX/NewgameWiki 的线上库一律不改；只读 P0 备份。
  • 对外发送默认 --no-publish 关闭，需显式 --publish。
