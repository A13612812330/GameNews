二、项目立项方案

定位

面向手游分发与内容运营的中文游戏资讯中台，将来源采集、清洗分类、评分评级、飞书同步、机器人提醒、日报和周报串成可审计工作流。

核心目标

  1. 聚合手游、Steam 和端游资讯。
  2. 识别新游、测试、上线、版本、活动和联动。
  3. 通过去重、机器评分及人工评级筛选。
  4. 生成今日简讯、日报海报和周报海报。
  5. 同步飞书游戏库，仅推送新增 S/A。
  6. 用私有 GitHub 支持跨电脑恢复。

边界

不做通用爬虫、不自动上架游戏、不上传真实密钥/数据库/缓存、不长期保存全部正文图片。

七、清洗、去重和评分

去重

  • URL 去重。
  • 游戏名 + 标题内容归一键去重。
  • 去标点和部分状态词后比较。

规则冲突：去重器会移除“测试服”，而既有要求是体验服/测试服独立。

评分

基础 50；有效事件、官方、日期、手游来源、TapTap 排名和重点 IP 加分；论坛、排行合集、抽奖、折扣、纯英文等扣分；范围 10–95。

人工评级

文章 score 用于资讯排序；飞书评级用于游戏等级。每轮先回写人工评级，再同步事件；新增 S/A 提醒，B/C 静默。
